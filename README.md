## ✨ Imkoniyatlar

- 🔎 Film nomini yozgan zahoti qidirish (debounce bilan — har harfda so'rov yuborilmaydi)
- 🪟 Film haqida batafsil ma'lumot oynasi (modal)
- ❤️ Sevimli filmlar — `localStorage` da saqlanadi
- ✨ Yuklanish skeleti (shimmer) va silliq animatsiyalar

## 🛠️ Texnologiyalar

React, Vite, Axios, OMDb API.

## 🚀 Ishga tushirish

```bash
git clone https://github.com/Zikrillayev77/movie.git
cd movie
npm install
npm run dev
```

Brauzerda `http://localhost:5173` manzilini oching.

Production uchun build:

```bash
npm run build
npm run preview
```
